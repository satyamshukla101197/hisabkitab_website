# HisabKitab website

A responsive static website made with HTML, CSS and JavaScript. No framework or build step is required.

## Pages
- `index.html` — landing page
- `about.html` — about the product
- `features.html` — feature overview
- `how-it-works.html` — workflow overview
- `contact.html` — contact page
- `privacy.html` and `terms.html` — starter legal pages
- `assets/logo.svg` — custom HisabKitab ledger/check logo

## Run locally
Open `index.html` in a browser or serve the folder using any static web server.

## Before publishing
1. Replace `hello@yourdomain.com` with your real business email.
2. Review and replace the privacy policy and terms with legally appropriate text for your actual app and data practices.
3. Add official Play Store/App Store links when available.
4. Verify all feature descriptions against what the app currently supports.
5. Check trademark and domain availability before investing in the brand.

The dashboard figures are illustrative sample data, not real customer information.
